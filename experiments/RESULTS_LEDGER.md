- **EVERY cell declines with index, including the RANDOM control.** Correlations run -0.46 to -0.95 and not one is positive, so the gradient is not a property of the head set: a band-matched random draw shows it too (-0.53). The check did find a real limitation elsewhere: **Qwen2-VL horizontal declines monotonically with panel index**. Ultravox is flat at spread 0.04.

## 21. Is it SHAREDNESS, or just being in the discovered top-100?

Every control in sections 3 and 19 is drawn from OUTSIDE the top-K with the subset's per-layer counts. That separates DEPTH. It does not separate 'shared with the text backbone' from 'in the top-100 at all', which is the objection the sufficiency claim actually has to answer. These draws come from INSIDE the top-100, so the only thing that varies is how much of the draw is shared.

Two cells per arm, three seeds each. **Cell B carries the power.** Its comparison set is the already-run audio-only subset of the SAME SIZE, which is also inside the top-100 and contains ZERO shared heads — so the two differ only in shared fraction. **Cell A is the cell matched on size, and it is structurally near-saturated**: on Ultravox any 71 of 100 must contain at least 42 of the 71 shared heads, so a null there is weak evidence and is not read as one.

**THE PAPER DOES NOT QUOTE THE INTERVALS IN THESE TABLES, and that is deliberate.** They are item-level bootstraps on a fixed set against a random draw, which is the comparison section 19's withdrawn interference row got wrong: the dominant variance is WHICH HEADS WERE DRAWN, and resampling items does not carry it. Pooling three draws shrinks the point estimate's dependence on any one draw but still does not propagate between-draw variance into the interval. They are computed here so the number exists and can be checked; the paper reports the per-draw values instead and says the subset exceeds every draw. **Do not reintroduce them into the text.**

Intervals use the ledger's convention throughout: item-level bootstrap, 10,000 resamples, resampling STRIPS not trials, independent resamples for the two arms (seed 0 vs seed 1). A paired resample would be tighter; independence is kept so every interval in the paper is comparable.

**How shared is each 'random' draw?** This decides how much contrast each cell has, and the two cells differ sharply. A draw the size of the SHARED subset cannot avoid being mostly shared: if 71 of 100 heads are shared and 71 are drawn, at least 42 must be shared. A draw the size of the UNSHARED subset has no such floor.

| arm | cell | draw size | minimum shared possible | shared actually drawn |
|---|---|---|---|---|
| ultravox | size of shared | 71 | 42/71 = 59% | 69%, 70%, 72% |
| ultravox | size of unshared | 29 | 0/29 = 0% | 69%, 69%, 69% |
| qwen2_audio | size of shared | 66 | 32/66 = 48% | 68%, 73%, 65% |
| qwen2_audio | size of unshared | 34 | 0/34 = 0% | 62%, 65%, 68% |
| salmonn | size of shared | 74 | 48/74 = 65% | 72%, 70%, 72% |
| salmonn | size of unshared | 26 | 0/26 = 0% | 69%, 73%, 81% |

- **The same-size control under the shared subset is a LOW-CONTRAST comparison, not a sharedness-free one:** 100% shared against roughly 70% shared, with a structural floor of 48-65%. A small difference there is what a small contrast predicts and must not be read as a null.
- **The control under the unshared subset is the high-contrast one:** 0% shared against roughly 70%, more than twice the contrast. That is where sharedness can actually be tested.
- Read against contrast, the two cells agree within every arm: sharing more helps on Qwen2-Audio and Ultravox at both contrasts and hurts on SALMONN at both. Only Qwen2-Audio's wide-contrast gap excludes zero. **Two contrasts per arm is a direction, not a dose-response.**

- **The powered cell separates on 1 of 3 arms.** Shared fraction is the ONLY thing that differs between the two sets — depth, size and top-100 membership are all held — so where the interval excludes zero, sharedness itself is doing causal work. Excludes zero and positive: qwen2_audio. Spans zero: ultravox, salmonn.
- **What this costs the writeup.** The sufficiency numbers in section 19 are unchanged: the shared subset still carries the effect on all three arms against its depth-matched control. What cannot be asserted is that it does so BECAUSE it is shared. **Write sufficiency as established on all three arms, and the sharedness explanation as established on one, consistent in direction on a second, and reversed on the third.** Do NOT write that an equal-sized draw from the top-100 refutes sharedness: at that size the draw is itself 65-73% shared and cannot be less than 48-65%, so it is a low-contrast comparison rather than a null. The table above gives the contrast for each cell and must be read before either is quoted.
- **Read the per-seed columns before reading any interval here.** Three draws from the SAME top-100 span ultravox 0.417, qwen2_audio 0.533, salmonn 0.333 at the small size. Where a cell spans zero it is as much a statement about power as about the effect.
